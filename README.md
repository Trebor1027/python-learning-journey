# Python Learning Journey

**My journey learning Python through practical exercises and guided coursework.**

## About this repository

This repository documents my progress learning Python, primarily through the programming course by **Soy Dalto**.

It contains practical exercises, examples, and small programming challenges completed during my learning process.

My goal is to strengthen my programming fundamentals and progressively develop skills in automation, artificial intelligence, and software development.

## Topics covered

- **Python fundamentals:** variables, data types, operators, and user input.
- **Control flow:** conditional statements and loops.
- **Data structures:** lists, tuples, sets, and dictionaries.
- **Functions:** parameters, arguments, return values, and lambda expressions.
- **Error handling:** exceptions and basic debugging.
- **Regular expressions:** pattern matching and text processing.
- **File handling:** reading, writing, and processing TXT and CSV files.
- **Data processing and visualization:** introductory exercises with Pandas and charts.
- **Object-oriented programming (OOP):** introductory concepts, currently in progress.
