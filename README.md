# Python Learning Journey

**My journey learning Python through practical exercises and guided coursework.**

## About this repository

This repository documents my progress learning Python, primarily through the programming courses by **Soy Dalto**.

It contains practical exercises, programming examples, and small challenges completed throughout my learning process, covering Python fundamentals and object-oriented programming.

My goal is to build a solid foundation in programming and progressively develop my skills in automation, artificial intelligence, and software development.

## Topics covered

### Python Fundamentals

- **Variables and data types:** strings, integers, floats, booleans, and type conversion.
- **Operators:** arithmetic, comparison, and logical operators.
- **Control flow:** conditional statements (`if`, `elif`, `else`) and loops (`for`, `while`).
- **Data structures:** lists, tuples, sets, and dictionaries.
- **Functions:** parameters, arguments, return values, lambda expressions, and flexible arguments (`*args`).
- **Error handling:** exception handling and basic debugging.
- **Regular expressions:** pattern matching and text processing.
- **File handling:** reading, writing, and processing TXT and CSV files.
- **Data processing:** introductory exercises using Pandas.
- **Data visualization:** basic charts and graphical representations.

### Object-Oriented Programming (OOP)

As part of my continued learning, I started studying object-oriented programming through practical exercises.

Topics practiced include:

- **Classes and objects:** defining classes, creating instances, and working with attributes.
- **Methods:** defining and using methods within classes.
- **Encapsulation:** controlling access to attributes and working with getters and setters.
- **Inheritance:** creating relationships between classes and practicing multiple inheritance.
- **Polymorphism:** exploring different implementations and behaviors.
- **Method Resolution Order (MRO):** understanding how Python resolves methods in inheritance hierarchies.
- **Practical exercises:** applying OOP concepts to small programming challenges.

**Learning status:** The introductory Python course has been studied, while the OOP course remains partially completed. This repository reflects my actual learning progress.

# Mi aprendizaje de Python

## Sobre este repositorio

Este repositorio documenta mi proceso de aprendizaje de Python, principalmente a través de los cursos de programación de **Soy Dalto**.

Contiene ejercicios prácticos, ejemplos de código y pequeños desafíos que he realizado durante mi formación, desde los fundamentos del lenguaje hasta conceptos de programación orientada a objetos.

## Conocimientos practicados

### Fundamentos de Python

- **Variables y tipos de datos:** cadenas de texto, números enteros, decimales, booleanos y conversiones de tipos.
- **Operadores:** aritméticos, de comparación y lógicos.
- **Estructuras de control:** condicionales (`if`, `elif`, `else`) y bucles (`for`, `while`).
- **Colecciones:** listas, tuplas, conjuntos y diccionarios.
- **Funciones:** parámetros, argumentos, valores de retorno, funciones lambda y argumentos variables (`*args`).
- **Excepciones:** gestión de errores y depuración básica.
- **Expresiones regulares:** búsqueda de patrones y procesamiento de texto.
- **Manejo de archivos:** lectura, escritura y manipulación de archivos TXT y CSV.
- **Procesamiento de datos:** ejercicios introductorios utilizando Pandas.
- **Visualización de datos:** creación de gráficos y representaciones visuales básicas.

### Programación Orientada a Objetos (POO)

También he dedicado parte de mi aprendizaje a estudiar los fundamentos de la programación orientada a objetos mediante ejercicios prácticos.

Los temas que he trabajado incluyen:

- **Clases y objetos:** creación de clases, instancias y atributos.
- **Métodos:** definición y utilización de métodos dentro de las clases.
- **Encapsulamiento:** control del acceso a atributos y utilización de getters y setters.
- **Herencia:** relaciones entre clases y herencia múltiple.
- **Polimorfismo:** diferentes implementaciones y comportamientos de los objetos.
- **Orden de resolución de métodos (MRO):** funcionamiento de la búsqueda de métodos en jerarquías de herencia.
- **Ejercicios prácticos:** aplicación de los conceptos estudiados mediante pequeños programas.

**Estado del aprendizaje:** He estudiado el curso introductorio de Python y he avanzado parcialmente en el curso de POO, que todavía no he completado. Este repositorio refleja los conocimientos y ejercicios que he trabajado durante mi formación.
